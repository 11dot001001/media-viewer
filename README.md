# Media Viewer

**Разбор фото и видео без боли: серии, дубликаты, карта и чистка iPhone по облаку.**

После поездки на телефоне 3 000 снимков, из них половина — серии почти одинаковых кадров,
скриншоты и копии из мессенджеров. Media Viewer находит всё это сам, предлагает оставить
лучшее, а то, что вы уже удалили в облаке, находит на iPhone и удаляет и там —
чтобы не разбирать одно и то же дважды.

- **Серии.** Кадры подряд сгруппированы, самый резкий отмечен ★, синхронная лупа для сравнения.
- **Дубликаты.** Точные копии и пересжатые версии (например, из WhatsApp).
- **Быстрый отбор.** ← → листать, ↑ оставить, ↓ удалить, лента миниатюр внизу.
- **Категории и карта.** Скриншоты, мессенджеры, видео; снимки на карте по GPS.
- **Можно удалить.** Подсказки, что почистить: случайные кадры, закрытые глаза, лишние кадры серий, копии, старые скриншоты, мемы из мессенджеров.
- **AI по желанию.** Нейросеть раскладывает снимки по смыслу (люди, еда, документы, случайные кадры…) и ищет по описанию: «море», «рамен», «ночной город».
- **Текст на снимках.** Поиск по надписям на скриншотах, документах и чеках: «бронь», «Wi-Fi», номер заказа.
- **Люди.** Лица на снимках сами собираются в группы по людям; дайте группе имя — и в ленте появится фильтр «где мы вдвоём».
- **Статистика.** Год к году на одном графике, каждый день года, когда и чем вы снимаете, рекорды и серии.
- **Место на диске.** Сортировка «сначала тяжёлые», вес каждого дня и файла.
- **iPhone по проводу.** Найти на телефоне снимки из корзины облака и удалить их оттуда.
- **Безопасно.** Всё удаляется только после подтверждения и сначала в Корзину Windows.

Работает только на вашем компьютере: интерфейс открывается в браузере, файлы никуда не отправляются.

## Запуск

```bat
run.bat
```

При первом запуске создаётся окружение `.venv` и ставятся зависимости. Нужны Python 3.11+ и, для видео, `ffmpeg` в `PATH`. Потом откроется браузер на `http://127.0.0.1:8765/`.

Можно сразу передать папку: `run.bat "D:\Фото\Телефон"`. Без аргумента откроется последняя папка.

Тестовые данные: `.venv\Scripts\python tools\make_test_data.py` создаст `sample_media\` с сериями, дубликатами, скриншотами, видео, Live Photo и парой RAW+JPG.

## Что умеет

- **Просмотр** на весь экран с лентой миниатюр внизу: видно соседние кадры, их отметки, серии и границы дней; клик по миниатюре — переход.
- **Сначала тяжёлые** (выпадающий список «Порядок»): лента группируется по размеру — больше 1 ГБ, 100 МБ – 1 ГБ и так далее, с суммарным весом группы. Так сразу видно, что освободит больше всего места. Работает и в «Корзине отбора». Размер файла виден при наведении на плитку, вес дня — в заголовке дня.
- **Масштаб как в «Фото» на iPhone:** `Ctrl` + колесо мыши (или «щипок» на тачпаде) меняет число снимков в ряду от 2 до 30. При 2–7 в ряду лента группируется по дням, при 8–15 по месяцам, от 16 по годам. Те же уровни есть в боковой панели, в группе «Вид»: ползунок «В ряду» и переключатель «Дни · Месяцы · Годы».
- **Лента** по дням. Серии соединены цветной линией снизу, ★ — рекомендованный кадр, ⧉ — есть дубликат, `RAW`/`LIVE` — есть парный файл. Можно свернуть каждую серию в одну карточку.
- **Серии.** Кадры, снятые подряд (пауза до N секунд) и похожие по картинке. В режиме разбора кадры показаны рядом, программа сама предлагает оставить 1–2 самых резких. Есть синхронная лупа (`Z`, колесо меняет масштаб): все кадры увеличиваются в одной точке. `Enter` сохраняет решение и открывает следующую серию.
- **Дубликаты.** Точные копии ищутся по содержимому файла, похожие — по перцептивному хэшу (например, фото, пересжатое WhatsApp). ★ — лучшая копия: выше разрешение, есть EXIF, имя без «(1)».
- **Категории:** фото с камеры, скриншоты и записи экрана, видео, файлы из мессенджеров, прочее. Определяются по EXIF, имени, папке и размеру кадра.
- **Левая панель.** Сверху поиск (`/`): по имени файла, а после анализа AI — и по описанию. Ниже разделы и фильтры: тип, «Что на снимке», статус, период. Фильтры — кнопки-фишки, можно выбрать несколько; в заголовке «Фильтры» видно, сколько их включено, и одна кнопка «Сбросить». Период: кнопки годов и месяцев и календарь, где подсвечены дни со снимками (чем ярче, тем их больше). В календаре клик — день, второй клик — конец периода, «весь месяц» — месяц целиком. Клик по названию месяца открывает месяцы года, клик по году — все годы, так что к нужной дате не надо листать по месяцу; начатый период при этом не сбрасывается. У поездки за один месяц календарь открыт сразу. Группы сворачиваются кликом по заголовку. Внизу — настройки поиска серий и список клавиш.
- **Карта** по GPS из EXIF и метаданных видео. Справа — снимки из видимой области.
- **Статистика очистки.** В «Корзине отбора» видно, сколько места освобождено в папке и на телефоне и как изменился размер папки. Кнопка «Подробнее» открывает таблицу по всем папкам и историю очисток.
- **Корзина отбора.** Отмеченные `X` файлы собираются здесь и удаляются только после подтверждения. На обычном диске они уходят в Корзину Windows. На флешке, карте памяти или сетевом диске Корзины нет, поэтому файлы переносятся в папку `_rejected`. Парные RAW и Live-видео удаляются вместе со снимком.

## AI: категории по смыслу и поиск по описанию

Нейросеть нужна не всем, поэтому она не ставится вместе с программой. Всё делается на странице **AI** в меню слева:

1. **Выбрать и скачать модель.** Моделей по смыслу две, обе от Google:
   - [SigLIP 2](https://huggingface.co/google/siglip2-base-patch16-224), около 925 МБ вместе с ONNX Runtime (`requirements-ai.txt`). Быстрая: на видеокарте (DirectML, подходит любая) несколько сотен снимков в секунду, на процессоре медленнее.
   - [EmbeddingGemma 2](https://huggingface.co/google/embeddinggemma-2), около 3,6 ГБ: 1,8 ГБ модели и своё окружение с ONNX Runtime для CUDA (≈ 2 ГБ, ставится той же кнопкой в папку модели). Чуть лучше понимает запросы на русском, но работает только на видеокартах NVIDIA и примерно в 10 раз медленнее: ~30 снимков в секунду на RTX 5080 (2329 снимков — полторы минуты, 30 тысяч — около 20 минут). Считает в отдельном процессе (`gemma_worker.py`), потому что ONNX Runtime с CUDA и с DirectML в одном окружении не уживаются.

   Модели лежат в `data/ai/`, кнопка «Удалить модель» освобождает место. Переключаться можно в любой момент. Результаты анализа хранятся отдельно для каждой модели, так что после переключения на уже проанализированную модель пересчитывать ничего не нужно. Выбранная модель запоминается в `data/ai/settings.json`.
2. **Запустить анализ.** Отдельная кнопка для открытой папки. Модель смотрит на миниатюры из индекса, сами файлы не читаются. Снимки, добавленные после анализа, проверяются той же кнопкой.
3. **Пользоваться.** Поиск в левой панели начнёт искать и по описанию (Enter — искать, Esc — сбросить, результаты от самых подходящих), а в фильтрах появится группа «Что на снимке» с категориями: люди, животные, еда и напитки, природа, город и здания, транспорт, документы и чеки, экраны, мемы и картинки, случайные кадры. Клик по категории оставляет в ленте только её, можно выбрать несколько.

Модель работает без интернета, снимки никуда не отправляются. Запросы понимает на русском и английском.

**Похожие снимки.** Клавиша `F` в ленте или в просмотре (там же кнопка «Похожие») показывает снимки, похожие по смыслу и композиции: то же место, тот же вид, те же люди. Картинку можно и просто перетащить в окно из проводника или браузера — найдутся похожие на неё снимки в папке (сама картинка никуда не сохраняется).

**Оценка кадра** — там же, отдельная карточка со своими кнопками «Скачать модель» (три модели лиц, ≈ 42 МБ: [YuNet](https://huggingface.co/opencv/face_detection_yunet), MediaPipe Face Mesh и [SFace](https://huggingface.co/opencv/face_recognition_sface) для страницы «Люди») и «Оценить фото»:
- Находит лица и проверяет, открыты ли глаза (по точкам век) и резко ли лицо. Лица ищутся на миниатюре, оригинал читается только для снимков с людьми. Прохожие на заднем плане не учитываются.
- ★ в сериях выбирается заново: сначала кадры, где ни у кого не закрыты глаза, затем по резкости (лиц, если они есть на всех кадрах), открытости глаз и красоте кадра по выбранной модели по смыслу. В разборе серии кадры с закрытыми глазами помечены.
- В группе «Что на снимке» появляются фильтры «Закрыты глаза» и «Лучшие кадры», на плитках — значок закрытых глаз, в информации о снимке (`I`) — строка «Оценка кадра».
- Около 40 фото в секунду на процессоре (1857 фото «Japan Test» — 18 секунд); первыми оцениваются кадры серий.

## Текст на снимках

Карточка **«Текст на снимках»** на странице AI читает надписи на фото встроенным распознаванием Windows (Windows.Media.Ocr). Модель качать не нужно, кнопка «Установить» ставит только пакеты winrt для Python, около 2 МБ.
- Распознаются языки, для которых в Windows установлен языковой пакет. Русский движок читает и латиницу. Японских иероглифов без японского пакета не будет.
- Читаются оригиналы (до 2000 px), около 30 фото в секунду: сначала скриншоты, потом документы, экраны и мемы, потом остальные. Файлы, которые есть только в облаке, и снимки с телефона пропускаются.
- Искать — в обычном поиске слева. Снимки с найденным текстом идут сразу после совпадений по имени файла, перед результатами по смыслу. Регистр, «ё/е» и пробелы в номерах не важны. Похожие русские и латинские буквы (М/M, о/o, п/n) считаются одной буквой: распознавание часто их путает.
- Прочитанный текст виден в информации о снимке (`I`), там же его можно скопировать.

## Люди

Оценка кадра заодно запоминает отпечаток каждого лица (SFace: 128 чисел; у одного человека на разных снимках они похожи, у разных — нет). По ним страница **Люди** собирает лица в группы:
- Сначала склеиваются почти одинаковые лица (серии), потом группы — по среднему сходству всех их лиц. Лица с одного снимка — всегда разные люди. На снимках из поездки двое главных людей разошлись чисто: 277 и 201 снимок; 15 тысяч лиц группируются за несколько секунд.
- Показываются группы, которые встречаются хотя бы на трёх снимках. Прохожих, статуи и персонажей можно **скрыть**.
- **Имя:** впишите в карточке и нажмите Enter. Человек появится в фильтре «Кто на снимке» слева; несколько людей сразу — снимки, где они вместе. Похожие лица при следующих группировках подтягиваются к нему сами.
- **Склейка:** то же имя у другой группы склеивает их в одного человека.
- **Чужие лица:** кнопка «Лица» показывает все лица группы — отмеченные уходят из неё и больше ни к кому не подбираются.
- Лица меньше 48 px не узнаются (отпечаток выходит случайным). Имена хранятся в индексе папки. Если папка оценивалась до появления «Людей», её нужно оценить ещё раз — снимки пересчитаются сами.

## Можно удалить

Страница **Можно удалить** собирает подсказки по неразобранным снимкам — каждый снимок в одной группе, от самых очевидных:
случайные кадры (смаз, темнота, палец на объективе — по AI) · закрыты глаза, а в серии есть кадр лучше · лишние кадры серий (кроме ★) · точные копии · пересжатые копии · скриншоты старше года · мемы и картинки из мессенджеров · фото экранов.

У группы видно, сколько места она занимает, и есть кнопка «Отметить все»; плитки работают как в ленте (`X`, `P`, двойной клик). Отмеченное попадает в «Корзину отбора» и удаляется только после подтверждения там. Подсказки учитывают фильтры слева.

## Статистика

Страница **Статистика** в меню слева считается по снимкам открытой папки с учётом фильтров слева:
- **Плитки:** сколько снято (фото и видео), самый активный день, самая длинная серия дней подряд со съёмкой, в среднем за день съёмки, общая длина видео. Клик по дню или серии открывает их в ленте.
- **Год к году:** линия на каждый год по месяцам — выбранный год синим, год для сравнения оранжевым, остальные серым. Режим «С начала года» показывает нарастающий итог; для незаконченного года сравнение идёт «к этому же дню» прошлого года. Клик по месяцу открывает его в ленте, под графиком — таблица по месяцам.
- **Каждый день года:** календарь-тепловая карта, клик по дню — открыть его в ленте.
- **По годам** (фото и видео), **когда снимаете** (часы и дни недели), **что на снимках** (если папка проанализирована AI), **чем снимали** (камеры) и несколько фактов: первый и последний снимок, самый долгий перерыв, самые активные дни.

## Облако и телефон: не разбирать одно и то же дважды

**Быстрый путь: из корзины облака.** Разберите папку облака и откройте «Корзину отбора». Затем:
1. Нажмите «Найти на телефоне».
2. На каждом файле появится значок: зелёный телефон — копия найдена на iPhone, серый перечёркнутый — не найдена.
3. При удалении отметьте «Удалить и с телефона». Вместе со снимком удалятся его Live-видео и правки (`.AAE`, `IMG_E…`).

Сначала файлы уходят из облака в Корзину Windows, потом удаляются с телефона. С телефона при этом ничего не копируется: сверка идёт по размеру и дате съёмки.

**Подробный путь: режим «Телефон…»** — сверка всего телефона с облаком:

1. **Откройте папку облака** (например, `D:\Yandex.Disk\Фотокамера`) и разберите её. Всё, что вы удаляете, запоминается в **журнале удалений**: дата съёмки, камера, размер, хэши и миниатюра. Самих файлов в журнале нет.
2. **Подключите iPhone** кабелем, разблокируйте его и нажмите «Доверять». В программе нажмите «Телефон…».
3. Снимки телефона разойдутся на три группы (слева, «Сверка с облаком»):
   - **Удалены в облаке.** Сразу помечены к удалению.
   - **Есть в облаке.** На телефоне это лишние копии. Кнопка «"Есть в облаке" → к удалению» помечает их все.
   - **Новые.** В облаке их нет, их надо разобрать как обычно.
4. В «Корзине отбора» нажмите «Удалить с телефона». Через провод у iPhone нет «Недавно удалённых», поэтому снимки, которых нет в облаке, перед удалением копируются в Корзину Windows.

Как это устроено:
- **Без копирования.** Сначала сверка идёт только по списку файлов (размер + дата съёмки): Яндекс хранит файлы байт в байт, хотя и переименовывает их. Совпавшие снимки с телефона не копируются, миниатюра берётся из облака. Остальное копируется и сверяется по EXIF и похожести картинки.
- **Защита от массового копирования.** Если не совпало больше 1 500 файлов или 10 ГБ, программа сначала спросит, копировать ли их.
- **Время.** Список файлов iPhone читается примерно 25–30 минут на 30 тысяч файлов. «Найти на телефоне» из корзины читает только папки нужных месяцев, это несколько минут.
- **Защита от удаления не тех файлов.** iPhone перенумеровывает файлы после каждого удаления, поэтому программа ничего не запоминает между подключениями. Найденным считается только файл, который программа прочитала с телефона целиком и чей SHA-1 совпал с облачным. Перед удалением каждого файла эта проверка повторяется: имя, размер и SHA-1 всего файла. При любом расхождении или ошибке чтения файл не трогается. Чтобы проверить ещё и глазами, во вкладке «Есть на телефоне» найденные файлы показаны парами: облачный оригинал и миниатюра, присланная самим iPhone.

## Клавиши

| Где | Клавиши |
|---|---|
| Лента | `/` — поиск, `F` — похожие снимки, `Ctrl` + колесо — масштаб, `←→↑↓` навигация, `Shift` + стрелки выделение, `Enter` открыть, `P` оставить, `X`/`Del` удалить, `U` снять отметку, `S` разобрать серию, `C` сравнить выбранные, `Ctrl+A`, `Ctrl+Z` |
| Просмотр | `←→` листать, `↑` оставить, `↓` удалить (сразу переход к следующему; `P`/`X` тоже работают), `I` информация, `F` похожие снимки, `Z` или клик — 100 %, `Esc` |
| Разбор серии | клик или `1`–`9` переключить кадр, `Z` лупа, `Enter` сохранить и дальше, `Tab` пропустить, `Esc` |

Буквы работают и в русской раскладке.

## Устройство

- `mediaviewer/media.py` — чтение JPEG/PNG/HEIC/RAW/видео, EXIF и GPS, миниатюры, pHash/dHash, резкость (дисперсия лапласиана).
- `mediaviewer/grouping.py` — серии и дубликаты.
- `mediaviewer/classify.py` — правила классификации.
- `mediaviewer/ai.py` — нейросеть: установка пакетов и моделей, выбор модели по смыслу, анализ миниатюр, категории по смыслу, поиск по тексту; SigLIP 2.
- `mediaviewer/gemma.py`, `mediaviewer/gemma_worker.py` — EmbeddingGemma 2: окружение с CUDA, отдельный процесс модели, пороги категорий и красоты, подобранные по разметке SigLIP.
- `mediaviewer/faces.py`, `mediaviewer/quality.py` — оценка кадра: лица, закрытые глаза, резкость лиц, отпечатки лиц.
- `mediaviewer/people.py` — люди: группировка лиц, имена, склейка, исключение чужих лиц.
- `mediaviewer/ocr.py` — текст на снимках: распознавание Windows и поиск по тексту.
- `mediaviewer/library.py` — индекс в SQLite, фоновое инкрементальное сканирование (повторное открытие проверяет только изменённые файлы).
- `mediaviewer/journal.py` — журнал удалений (отпечатки удалённых снимков).
- `mediaviewer/matching.py` — сверка телефона с облаком и журналом.
- `mediaviewer/wpd.py`, `mediaviewer/phone.py` — доступ к iPhone/Android по MTP (Windows Portable Devices): список, копирование, удаление.
- `mediaviewer/app.py` — HTTP API (FastAPI).
- `static/` — интерфейс без сборки (Leaflet для карты); `static/stats.js` — страница статистики.

Индекс и миниатюры лежат в `data/libraries/<хэш пути>/`, телефоны — в `data/phones/`, журнал — в `data/journal.db`. Сами папки с фото не трогаются. Отметки «оставить» и «удалить» хранятся там же и не теряются между запусками.
